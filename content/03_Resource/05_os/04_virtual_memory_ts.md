# Memory 트러블슈팅 사례

## 사례 선정 기준

- Memory Leak, Swap 증가, Thrashing, OOM, OOM Killer에 의한 Process 종료 중 하나와 관련된 공개 사례를 선택한다.
- 장애를 겪은 조직이 직접 공개한 기술 블로그, 발표 자료, 사후 분석 문서를 우선 사용한다.
- 증상과 실제 원인을 구분할 수 있고, 조사 과정이나 근거가 공개된 사례를 선택한다.

### 명령어

```bash
# 예: 메모리와 swap 사용량 확인
free -m

# 예: swap in/out과 page fault 추이 확인
vmstat 1

# 예: process별 RSS 확인
ps -eo pid,rss,vsz,comm --sort=-rss | head

# 예: OOM Killer 동작 여부 확인
dmesg -T | grep -i -E 'oom|killed process'
```
