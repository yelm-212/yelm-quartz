# OSTEP Security

## 학습 범위

OSTEP Ch 52~57을 OS 6주 학습 뒤에 별도 범위로 공부한다.

## 학습 목표

- 보안 목표와 위협 모델을 설명할 수 있다.
- 사용자의 신원을 확인하는 인증 방식을 비교할 수 있다.
- 주체가 객체에 수행할 수 있는 작업을 접근 제어 정책으로 표현할 수 있다.
- 대칭키 암호화, 공개키 암호화, 해시의 역할을 구분할 수 있다.
- 분산 시스템에서 통신 상대와 메시지를 신뢰하기 어려운 이유를 설명할 수 있다.
