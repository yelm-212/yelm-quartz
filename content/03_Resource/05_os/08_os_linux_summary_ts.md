# File Descriptor 고갈 트러블슈팅 사례

## 사례 선정 기준

- 직접 경험한 Jenkins `Too many open files` 사례를 주 사례로 사용한다.
- 비교용으로 File Descriptor 고갈이나 자원 누수와 관련된 공개 사례를 하나 더 선택한다.
- 같은 증상이 서로 다른 원인에서 나올 수 있다는 점을 두 사례 비교로 확인한다.
- 공개할 수 없는 식별 정보는 일반화해서 기록한다.

## 3. 확인할 로그, 메트릭, 명령어 정의

### FD 사용량

<!-- 대상 process가 연 FD 수와 시간에 따른 증가 추이를 확인한다. -->

```bash
ls /proc/<pid>/fd | wc -l
```

### FD의 종류

<!-- 일반 파일, socket, pipe 중 무엇이 늘어나는지 확인한다. 종류에 따라 의심할 코드 경로가 달라진다. -->

```bash
lsof -p <pid> | awk '{ print $5 }' | sort | uniq -c | sort -rn
```

### Limit

<!-- process에 실제로 적용된 Soft/Hard Limit과 시스템 전체 file handle 사용량을 확인한다. -->

```bash
prlimit --pid <pid>
cat /proc/<pid>/limits
cat /proc/sys/fs/file-nr
```
