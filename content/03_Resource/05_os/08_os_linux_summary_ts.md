## 3. 확인한 로그, 메트릭, 명령어

```bash
# 예: 대상 process가 연 FD 수 확인
ls /proc/<pid>/fd | wc -l

# 예: FD의 종류별 분포 확인
lsof -p <pid> | awk '{ print $5 }' | sort | uniq -c | sort -rn

# 예: process에 적용된 limit 확인
prlimit --pid <pid>

# 예: 시스템 전체 file handle 사용량 확인
cat /proc/sys/fs/file-nr
```
