# Slow Query 트러블슈팅 사례

## 사례 선정 기준

- Slow Query, 잘못된 Query 배포, Index 미사용, 잘못된 Composite Index 중 하나와 관련된 공개 사례를 선택한다.
- 장애를 겪은 조직이 직접 공개한 기술 블로그, 발표 자료, 사후 분석 문서를 우선 사용한다.
- 처음 관찰된 증상과 실제 원인을 구분할 수 있고, 조사 과정이나 근거가 공개된 사례를 선택한다.

## 3. 확인할 로그, 메트릭, 명령어 정의

### 느린 Query 식별

<!-- Slow Query Log와 실행 통계에서 대상 Query를 좁힌다. 실행 시간뿐 아니라 실행 횟수도 함께 확인한다. -->

```sql
-- MySQL Slow Query Log 설정 확인
SHOW VARIABLES LIKE 'slow_query%';
SHOW VARIABLES LIKE 'long_query_time';

-- PostgreSQL 실행 통계 상위 Query 확인
SELECT query, calls, mean_exec_time, rows
FROM pg_stat_statements ORDER BY mean_exec_time DESC LIMIT 10;
```

### Execution Plan

<!-- 접근 방식, 사용된 Index, 예상 행 수와 실제 행 수의 차이, Join 순서를 확인한다. -->

```sql
EXPLAIN SELECT ...;
EXPLAIN ANALYZE SELECT ...;
```

<!-- 운영 환경에서 `EXPLAIN ANALYZE`는 Query를 실제로 실행하므로 사용 조건을 함께 기록한다. -->
